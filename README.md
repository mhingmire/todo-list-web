# ToDo-List Web App

A simple web-based To-Do List application that allows users to **sign up, log in, add tasks, mark them as completed, edit, delete, and filter tasks**. User tasks are saved individually using `localStorage`, so each user can maintain their own task list.

---

## Features

- **User Authentication**: Sign up and log in with a username and password.
- **Add Tasks**: Add tasks with optional due dates.
- **Edit & Delete**: Edit existing tasks or delete them.
- **Mark Complete**: Mark tasks as completed; completed tasks are visually distinguished(checked out).
- **Filter Tasks**: View all tasks, only active tasks, or only completed tasks.
- **Persistent Storage**: Each user's tasks are saved locally and loaded when they sign in.
- **Logout**: Securely log out and hide tasks from previous users.

---

## Technologies Used

- **HTML**: Structure of the webpage
- **CSS**: Styling and layout
- **JavaScript**: Task functionality, user authentication, and `localStorage` persistence
